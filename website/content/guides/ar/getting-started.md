# البدء السريع

## التثبيت

نزّل أحدث مثبّت من [صفحة التنزيل](/ar/download) أو [GitHub Releases](https://github.com/AQBot-Desktop/AQBot/releases).

### macOS

| الشريحة | الملف |
|---------|-------|
| Apple Silicon (M1 / M2 / M3 / M4) | `AQBot_x.x.x_aarch64.dmg` |
| Intel | `AQBot_x.x.x_x64.dmg` |

1. افتح `.dmg` واسحب **AQBot** إلى مجلد **Applications**.
2. أطلق AQBot. إذا حظرت macOS التطبيق، اذهب إلى **إعدادات النظام ← الخصوصية والأمان** وانقر **فتح على أي حال**.

::: warning macOS: "التطبيق تالف" أو "لا يمكن التحقق من المطوّر"
يُوقَّع AQBot بشهادة توقيع الشيفرة الخاصة بالمشروع، وليس بشهادة Apple Developer ID، لذا قد تعرض macOS بعد التنزيل من المتصفح رسالة "AQBot تالف ولا يمكن فتحه" أو "لا يمكن فتح AQBot لأنه لا يمكن التحقق من المطوّر".

لا حاجة إلى تعطيل Gatekeeper على مستوى النظام بالكامل — اسمح لـ AQBot فقط:

1. في Finder، انقر على `AQBot.app` مع الضغط على Control، واختر **فتح**، ثم انقر **فتح** مرة أخرى.
2. إذا استمر الحظر، اذهب إلى **إعدادات النظام ← الخصوصية والأمان**، وابحث عن AQBot في قسم **الأمان** وانقر **فتح على أي حال**.
3. أعد تشغيل AQBot.

السماح عبر Gatekeeper وإذن تسهيلات الاستخدام إعدادان منفصلان. لاستخدام شريط أدوات تحديد النص، فعّل AQBot أيضاً في **إعدادات النظام ← الخصوصية والأمان ← تسهيلات الاستخدام** باتباع التنبيه داخل التطبيق.
:::

### Windows

| البنية | الملف |
|--------|-------|
| x64 (معظم الأجهزة) | `AQBot_x.x.x_x64-setup.exe` |
| ARM64 | `AQBot_x.x.x_arm64-setup.exe` |

شغّل المثبّت واتبع المعالج.

### Linux

```bash
# Debian / Ubuntu
sudo dpkg -i AQBot_x.x.x_amd64.deb

# Fedora / openSUSE
sudo rpm -i AQBot_x.x.x_x86_64.rpm

# AppImage
chmod +x AQBot_x.x.x_amd64.AppImage
./AQBot_x.x.x_amd64.AppImage
```

## الإعداد الأولي

### 1. فتح الإعدادات

أطلق AQBot وانقر على **أيقونة الترس** في أسفل الشريط الجانبي، أو اضغط <kbd>Cmd/Ctrl</kbd>+<kbd>,</kbd>.

### 2. إضافة مزوّد

انتقل إلى **الإعدادات ← المزوّدون** وانقر على زر **+**.

1. أدخل اسماً للعرض (مثلاً *OpenAI*).
2. اختر نوع المزوّد (OpenAI أو Anthropic أو Google Gemini، إلخ).
3. الصق مفتاح API الخاص بك.
4. أكّد **Base URL** — الطرف الرسمي مُملوء مسبقاً للأنواع المدمجة.

::: tip
يمكنك إضافة أي عدد من المزوّدين. كل مزوّد يدير مفاتيح API ونماذجه بشكل مستقل.
:::

### 3. جلب النماذج

انقر **جلب النماذج** للحصول على قائمة النماذج المتاحة من API المزوّد. يمكنك أيضاً إضافة معرّفات النماذج يدوياً إذا لزم.

### 4. ضبط النموذج الافتراضي

اذهب إلى **الإعدادات ← النموذج الافتراضي** واختر المزوّد والنموذج الذي تستخدمه المحادثات الجديدة افتراضياً.

---

## محادثتك الأولى

1. انقر **محادثة جديدة** في الشريط الجانبي (أو اضغط <kbd>Cmd/Ctrl</kbd>+<kbd>N</kbd>).
2. اختر نموذجاً من محدد النماذج في أعلى المحادثة.
3. اكتب رسالة واضغط <kbd>Enter</kbd>.
4. يبثّ AQBot الاستجابة في الوقت الفعلي. النماذج التي تدعم كتل التفكير (مثل Claude وDeepSeek R1) تعرض عملية الاستدلال في قسم قابل للطي.

|----------|---------|
| <kbd>Cmd/Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>A</kbd> | إظهار / إخفاء النافذة الحالية |
| <kbd>Cmd/Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Alt</kbd>+<kbd>A</kbd> | إظهار / إخفاء جميع النوافذ |

| <kbd>Cmd/Ctrl</kbd>+<kbd>N</kbd> | محادثة جديدة |
| <kbd>Cmd/Ctrl</kbd>+<kbd>,</kbd> | فتح الإعدادات |
| <kbd>Cmd/Ctrl</kbd>+<kbd>K</kbd> | لوحة الأوامر |
