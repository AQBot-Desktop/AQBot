# Быстрый старт

## Установка

Скачайте последний установщик со [страницы загрузки](/ru/download) или [GitHub Releases](https://github.com/AQBot-Desktop/AQBot/releases).

### macOS

| Чип | Файл |
|-----|------|
| Apple Silicon (M1 / M2 / M3 / M4) | `AQBot_x.x.x_aarch64.dmg` |
| Intel | `AQBot_x.x.x_x64.dmg` |

1. Откройте `.dmg` и перетащите **AQBot** в папку **«Программы»**.
2. Запустите AQBot. Если macOS блокирует приложение, перейдите в **Системные настройки → Конфиденциальность и безопасность** и нажмите **Всё равно открыть**.

::: warning macOS: «Приложение повреждено» или «Разработчик не верифицирован»
AQBot подписан собственным сертификатом подписи кода проекта, а не сертификатом Apple Developer ID, поэтому после загрузки из браузера macOS всё ещё может сообщать, что «Приложение AQBot повреждено и не может быть открыто» или что «Не удаётся открыть AQBot, так как не удалось проверить разработчика».

Отключать Gatekeeper для всей системы не нужно — разрешите только AQBot:

1. В Finder нажмите на `AQBot.app`, удерживая Control, выберите **Открыть**, затем снова нажмите **Открыть**.
2. Если приложение по-прежнему блокируется, перейдите в **Системные настройки → Конфиденциальность и безопасность**, найдите AQBot в разделе **Безопасность** и нажмите **Всё равно открыть**.
3. Снова запустите AQBot.

Разрешение Gatekeeper и разрешение «Универсальный доступ» — это разные настройки. Для панели инструментов выделения текста также включите AQBot в **Системные настройки → Конфиденциальность и безопасность → Универсальный доступ**, следуя подсказке в приложении.
:::

### Windows

| Архитектура | Файл |
|------------|------|
| x64 (большинство ПК) | `AQBot_x.x.x_x64-setup.exe` |
| ARM64 | `AQBot_x.x.x_arm64-setup.exe` |

Запустите установщик и следуйте мастеру. Запустите AQBot из меню «Пуск» или ярлыка на рабочем столе.

### Linux

| Формат | Архитектура | Файл |
|--------|------------|------|
| Debian / Ubuntu | x64 | `AQBot_x.x.x_amd64.deb` |
| Debian / Ubuntu | ARM64 | `AQBot_x.x.x_arm64.deb` |
| Fedora / openSUSE | x64 | `AQBot_x.x.x_x86_64.rpm` |
| Fedora / openSUSE | ARM64 | `AQBot_x.x.x_aarch64.rpm` |
| Любой дистрибутив | x64 | `AQBot_x.x.x_amd64.AppImage` |
| Любой дистрибутив | ARM64 | `AQBot_x.x.x_aarch64.AppImage` |

```bash
# Debian / Ubuntu
sudo dpkg -i AQBot_x.x.x_amd64.deb

# Fedora / openSUSE
sudo rpm -i AQBot_x.x.x_x86_64.rpm

# AppImage (любой дистрибутив)
chmod +x AQBot_x.x.x_amd64.AppImage
./AQBot_x.x.x_amd64.AppImage
```

## Начальная настройка

### 1. Открыть настройки

Запустите AQBot и нажмите на **значок шестерёнки** внизу боковой панели, или нажмите <kbd>Cmd/Ctrl</kbd>+<kbd>,</kbd>.

### 2. Добавить провайдера

Перейдите в **Настройки → Провайдеры** и нажмите кнопку **+**.

1. Введите отображаемое имя (например, *OpenAI*).
2. Выберите тип провайдера (OpenAI, Anthropic, Google Gemini и т.д.).
3. Вставьте ваш API-ключ.
4. Подтвердите **Base URL** — официальный endpoint предзаполнен для встроенных типов.

::: tip
Вы можете добавить столько провайдеров, сколько захотите. Каждый провайдер управляет своими ключами API и моделями независимо.
:::

### 3. Получить модели

Нажмите **Получить модели**, чтобы загрузить список доступных моделей из API провайдера. Вы также можете добавлять ID моделей вручную при необходимости.

### 4. Установить модель по умолчанию

Перейдите в **Настройки → Модель по умолчанию** и выберите провайдера и модель, которые новые разговоры должны использовать по умолчанию.

---

## Ваш первый разговор

1. Нажмите **Новый чат** в боковой панели (или нажмите <kbd>Cmd/Ctrl</kbd>+<kbd>N</kbd>).
2. Выберите модель из селектора моделей вверху чата.
3. Введите сообщение и нажмите <kbd>Enter</kbd>.
4. AQBot транслирует ответ в реальном времени. Модели с поддержкой блоков размышлений (например, Claude, DeepSeek R1) отображают процесс рассуждений в сворачиваемом разделе.

## Горячие клавиши

| Сочетание | Действие |
|-----------|---------|
| <kbd>Cmd/Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>A</kbd> | Показать / скрыть текущее окно |
| <kbd>Cmd/Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Alt</kbd>+<kbd>A</kbd> | Показать / скрыть все окна |
| <kbd>Cmd/Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>W</kbd> | Закрыть окно |
| <kbd>Cmd/Ctrl</kbd>+<kbd>N</kbd> | Новый разговор |
| <kbd>Cmd/Ctrl</kbd>+<kbd>,</kbd> | Открыть настройки |
| <kbd>Cmd/Ctrl</kbd>+<kbd>K</kbd> | Палитра команд |
| <kbd>Cmd/Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>G</kbd> | Переключить API-шлюз |
